ProtoDB documentation
=====================

ProtoDB is an embedded, transactional, object-oriented database for Python.

This site is being rewritten for ProtoDB 2.0 (spec section 13). Until then:

- the README in the repository root introduces the 2.0 API, and ``examples/`` holds
  runnable, self-checking scripts;
- the design is ``docs/superpowers/specs/2026-11-01-protodb-v2-design.md`` and every
  design decision is recorded in ``docs/decisions.md``;
- the API reference below is generated from the docstrings of the 2.0 modules;
- the 0.1 documentation pages are kept for reference in ``docs/legacy/sphinx-0.1/``.
